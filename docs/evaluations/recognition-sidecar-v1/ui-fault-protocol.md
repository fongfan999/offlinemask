# Packaged fault-injection protocol

Use only the separately identified Sidecar UI test app, verified local pack and synthetic input. Do not signal the normal OfflineMask processes.

1. Mask the reviewed H’Hen Niê synthetic sentence successfully; record the host PID and its bundled recognition helper child.
2. Stop that exact helper with SIGSTOP. Submit another synthetic draft. The supervisor must time out, kill/reap the helper, preserve the unchanged draft and show a recoverable error. No partial preview/session should be created.
3. Retry from the retained draft. A new helper PID must appear and complete the expected mask, while the app host PID remains unchanged.
4. Start a long synthetic draft and SIGKILL only its currently identified helper. The app must stay open, retain the draft, and allow a successful fresh-child retry.
5. Close the isolated app and confirm its helper exits. The original user apps stay untouched.

This checks unexpected termination and a fully stopped process. It does not simulate every possible native runtime fault or qualify all operating systems. Performance/replay evidence comes from a separate uninterrupted benchmark.
