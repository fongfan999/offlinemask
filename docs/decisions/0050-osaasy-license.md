# O’Saasy license choice

Recorded: 8 October 2026. Status: implemented (briefly replaced by MIT in [0116](0116-mit-license.md) on 20 October 2026, then restored).

The owner selected the [O’Saasy License Agreement](https://osaasy.dev/) for OfflineMask. This supersedes earlier documentation saying the project license had not been selected.

The agreement permits use, modification and redistribution subject to its terms, including a restriction on directly competing hosted, managed, SaaS or cloud offerings. Describe publication as **source available**: that restriction conflicts with the unrestricted fields-of-endeavor requirement in the [Open Source Definition](https://opensource.org/osd). Do not advertise it as OSI open source.

The owner supplied the copyright-holder name **Phong Phan**. The root [LICENSE.md](../../LICENSE.md) contains the official downloadable agreement with its copyright placeholders filled as “Copyright © 2026, Phong Phan.” The agreement terms are unchanged. A personal website is not required for the notice.

This choice applies to project-owned material. Dependencies, model weights, tokenizer resources and runtime libraries retain their upstream licenses and notices. Complete their redistribution review separately; the project license does not replace those obligations. Private vulnerability reporting also remains a release setup task.

Validation: checked the official agreement and Open Source Definition on the recorded date; updated current README, contributor guidance, PRD and product direction. Verified the license against the official download, allowing only the copyright-placeholder substitution. No runtime behavior changed.

Update, 25 October 2026: the owner set the naming rule, "my name is Phong Phan, my blog/my personal brand name is Wot Da Fong, so I think a new product will under the my personal brand, and of course, some places need my name, just use Phong Phan". The licensor and every copyright line (`LICENSE.md`, the README, the website footers, the Store listing) stay **Phong Phan**, because a copyright holder is a person. **Wot Da Fong** is the brand OfflineMask is published under: the Microsoft Store publisher name, and the website footer's "Thực hiện bởi" credit, linking to wotdafong.dev. It is written plainly, without the "?!" of the drawn logo. The license terms are unchanged.
