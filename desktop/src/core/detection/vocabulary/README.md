# Detection vocabulary

Every word list the masking rules use lives here, as data, in one place (decision 0161). The rules in `src/core/detection/` are a small number of mechanisms that read these files through `vocabulary.ts`; adding a document kind means adding words here, not branches there.

| File | Holds | Read by | Source |
| --- | --- | --- | --- |
| `places.json` | the provinces and cities (34 current, the names before), their aliases, countries | place of issue, public bodies, address ends, "a province is not a person", "a country is not a place" | generated by `scripts/build-places.mjs` from two MIT datasets; countries curated |
| `public-bodies.json` | state bodies, provincial departments (current and former), agencies | public bodies and their jurisdiction | Decree 45/2025/NĐ-CP arts. 8–9, Decree 24/2014/NĐ-CP |
| `people.json` | family names, name syllables, forms of address, ranks, roles | name shape, name cues, signatures, headings in capitals | family names from Wikipedia "Vietnamese name" (CC BY-SA 4.0); the rest curated |
| `organizations.json` | legal forms, organization kinds, units inside an organization, trade syllables, name stops | legal-prefix walker, departments, organization kind alone | Law on Enterprises 2020 for forms; the rest curated |
| `document-wording.json` | boilerplate by document kind, numbered words, column headings that hold wording, amount words, currencies, contract parties | phrase veto, cell under a heading, sex field | curated |
| `field-labels.json` | the labels before a name, address, date, account, identifier, code | labelled fields, identifiers, dates, address completion | curated |
| `units.json` | measures, packs, units of goods and services, the words of an address | goods cells, unit column, address completion | curated |

## Rules for the data

- Write entries as documents print them, with tone marks and in lower case. The loader folds a copy for the readers that compare without tone marks; never add an unaccented duplicate by hand.
- An entry is a phrase, not a regular expression. The few patterns that need a wildcard (a word before a number) are listed under `numbered`; `partyRoles` is the one exception and is marked as such.
- A closed public set (provinces, departments, legal forms) is downloaded or taken from the source named in the file's `$comment`, with its license, and regenerated by a script where one exists. A curated list says so.
- Before adding a word, check which mechanism will read it and whether the family it closes is open-ended. An open class (positions, products, subjects) belongs to the models, not to a list; the synthetic set (`pnpm documents:generate`) is the training and measurement data for that.
- Every change is measured: `pnpm test`, `pnpm test:models`, and `pnpm eval:documents` on the synthetic seeds and the owner's sets must not move.
