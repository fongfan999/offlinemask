# Code of conduct

Everyone taking part in this project, in issues, pull requests, reviews and discussions, is expected to be respectful and constructive. Disagree with ideas, not with people. Assume good faith, give reasons, and accept that maintainers make the final call on scope.

Unacceptable behaviour includes harassment, personal attacks, discriminatory remarks, publishing others' private information, and sustained disruption. It also includes posting real personal data of any kind, which this project is built to protect.

Reports can be sent privately through the repository's **Security → Report a vulnerability** channel or to a maintainer through their GitHub profile. Reports are handled confidentially. Maintainers may edit or remove contributions and may temporarily or permanently exclude anyone who breaks these rules.

This document is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
